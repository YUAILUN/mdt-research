# MDT Research

MDT 指 Multidisciplinary Team。本 skill 将科研问题组织成多个专业职能的审查，再形成可验证的研究计划。角色代表分析方法和职责，不对应真实人物，不模仿个人观点、经历或语言。默认用用户的语言；这些职能视角由 AI 生成，不声称真实专家参加。

## 选择模式与职能

用户给定的领域、角色、篇幅、资源和输出形式优先。通常选 6 个与问题相关且互补的职能；快速模式 4 个；深入模式最多覆盖全部 12 个。用户指定名单时依其顺序，不为凑人数添加无关角色。

先读 [职能索引](references/roles.md)，只加载入选角色的 `references/roles/<slug>.md`。领域机制角色结合当前研究领域提供专业框架，其他职能检查论证中的不同环节。需要自定义专业时可新增本轮角色，说明职责边界，不改写固定目录。

| 模式 | 重点 |
| --- | --- |
| 课题论证 / 默认 MDT | 机制、已有证据、实验、因果、统计和可重复性 |
| 方案审查 | 可识别性、对照、测量、样本、执行与失败条件 |
| 结果解读 | 数据质量、效应与不确定性、替代解释和推广范围 |
| 计算或 AI 研究 | 数据、模型、基线、消融、分布外验证和系统约束 |
| 技术转化 | 使用场景、成本、工程、验证阶段和利益相关者 |
| 第二轮评议 | 围绕会改变结论的具体分歧回应证据或假设 |

只在目标问题缺失或关键约束让方案无法成立时澄清。其他情况明确假设后开始。普通事实解释无需自动扩展成 MDT 会议。

## 工作流

### 1. 固定问题、决策与边界

用 1–3 句说明研究对象、核心问题、这次要支持的决策和成功条件。区分描述、预测、干预、机制解释与价值判断。保留用户材料中的时间、资源、研究阶段和否定约束。

将模糊目标写成候选假设与可测量结果。已有设计尽量先审查再修改，避免无依据重建整个课题。缺失的样本量、效应大小、预算或条件列为未知量，不自动编造。

### 2. 建立共享证据底座

优先使用用户材料；最新研究、精确数值、具体专业主张或高影响医学、法律、金融判断需要用宿主检索工具核验。优先原始论文、官方数据和方法文档。记录来源、日期、设计类型、支持的主张与局限。

区分四种状态：已核验事实；用户材料中的主张；合理推断；待验证假设。无检索能力或用户要求离线时明确范围，使用现有材料开展；不得把未读文献写成支持证据，也不得编造作者、DOI 或实验结果。

### 3. 分职能审查

各职能使用同一问题和事实底座，检查其负责的论证环节。先形成各自判断，再综合，避免提前统一观点；也不强迫制造反对意见。

每个职能给出：

- **判断**：对当前研究问题或设计的具体结论及成立条件。
- **依据与方法**：把该职能的方法应用到具体变量、假设或资源约束。
- **关键缺口**：最可能改变结论的混淆、测量问题、替代解释或失败条件。
- **验证动作**：可区分竞争解释的实验、对照、分析或决策阈值。

没有适用任务的职能可以省略。用职责标题与清晰论证表达差异，不编造角色资历或以权威口吻越过证据。涉及具体统计、因果或实验规则时，核对适用假设；不要机械套用模板。

### 4. 处理实质分歧

优先聚焦 2–4 个会改变研究决策的争点：机制、因果识别、测量、评价目标、成本或价值取舍。对每个争点说清争议的前提、支持范围以及能判别的证据。若意见一致，指出一致背后的共同前提和未检验部分。

第二轮只让相关职能回应具体主张，写清认可部分、保留意见、所需新证据和是否修改判断。不同价值不能简单用更多数据“解决”，也不能用人数表决决定科学真伪。

### 5. 综合为验证计划

先给当前最有依据的综合判断，再说明证据强度、未决问题与适用边界。按信息价值、成本与执行条件优先选 1–3 项下一步，每项至少含：

| 假设或争点 | 实验 / 分析及对照 | 主要指标 | 支持 / 反驳条件 | 资源与限制 |
| --- | --- | --- | --- | --- |

具体阈值缺少依据时写出应如何预先确定，而非任意填数。样本量需依据设计、效应、不确定性和目标精度说明计算条件；信息不足时给计算所需输入。

同一模型产生的多个职能判断不是独立专家样本。综合信心依据证据质量、可重复性及适用性，不依据“多少角色同意”。仅拟定计划，不把提案写成已执行的实验或已证实的结论。

## 默认交付

```text
当前综合判断与研究目标
必要假设、共享证据及已知限制
入选职能与逐项评议（可用紧凑表格）
关键分歧与判别证据
优先验证计划及何种结果会改变结论
已实际核验的来源（贴近主张引用）
```

按用户要求压缩或展开。方法必须落到当前问题，避免“需要更多数据”等泛泛建议。追问某职能时只深入该职能，沿用已核验事实并说明是否改变综合判断。

## 可选本地工具

在 skill 目录中先运行 `python3 scripts/mdt.py --help`。

```bash
python3 scripts/mdt.py list
python3 scripts/mdt.py show statistics causal-inference
python3 scripts/mdt.py panel --preset biomed --question '如何验证候选靶点？'
```

工具只列出职能或组装本地提示包，不调用模型、访问网络或执行实验。无 Python 时直接读取 Markdown，工作流完整可用。预设只是起点，应按题目调整。

调用与验收示例见 [examples.md](references/examples.md)，来源与设计范围见 [provenance.md](references/provenance.md)。
